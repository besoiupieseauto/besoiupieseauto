# Formare carte produs

Modul admin pentru configurarea regulilor de titlu produs și tab-uri descriere.

## Funcționalități

- **Titlu produs** — segmente sau template liber, per canal (website, pieseauto, oem)
- **Tab-uri descriere** — configurare tab-uri pagină produs (prose, fields, table, chart, reviews…)
- **Profiluri scope** — implicit, per categorie, per proiect/canal
- **Preview live** — titlu și tab-uri cu sample-uri de test
- **Salvare/reset** — persistență JSON

## Acces

`/admin/product-formation` — necesită permisiune `module.product_formation` sau `produse.list`.
